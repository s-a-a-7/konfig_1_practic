# **Эмулятор работы в командной строке UNIX-подобной ОС**

# Этап 1. REPL
1. Графический интерфейс (GUI).
2. Заголовок окна содержит имя VFS.
3. Парсер с корректно обработкой аргументов в кавычках.
4. Сообщение об ошибке выполнения команд (неизвестная команда, неверные аргументы).
5. Команды-заглушки, которые выводят свое имя и аргументы: ls, cd.
6. Команда exit.

# Этап 2. Конфигурация
1. Параметры командной строки:
   - Путь к физическому расположению VFS.
   - Путь к стартовому скрипту.
2. Стартовый скрипт для выполнения команд эмулятора: выполняет команды последовательно, ошибочные строки пропускает. При выполнении скрипта на экране отображается как ввод, так и вывод, имитируя диалог с пользователем.
3. Несколько скриптов реальной ОС, в которой выполняется эмулятор для тестирования всех поддерживаемых параметров командной строки.

# Этап 3. VFS
1. Виртуальную файловую систему (VFS)
2. Все операции производятся в памяти
3. Источником VFS является директория на диске пользователя
4. Сообщение об ошибке загрузки VFS
5. Информация о загруженной VFS по служебной команде vfs-info (имя VFS и хеш SHA-256 ее данных)
6. Несколько скриптов реальной ОС для тестирования работы c различными вариантами VFS (минимальный, несколько файлов, не менее 3 уровней файлов и папок)
7. Стартовый скрипт для тестирования всех реализованных команд, в том числе работа с VFS и обработка ошибок
